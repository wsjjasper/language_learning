# 基线 / 月度测量（第 1 周一次，之后每月第一个周末，约 30 分钟）

每次用 **同样的方法**，结果才有可比性。

## 1. 口语：2 分钟自由口语（10 分钟）

1. 从下面按月轮换选一个题目，**不准备**，直接用手机录音（Voice Memos 等）说满 2 分钟：
   - 第 0/3 月：Walk me through what you worked on last week and what's blocking you.
   - 第 1 月：Tell me about a technical decision you disagreed with and what happened.
   - 第 2 月：What's something you did last weekend, and would you recommend it?
2. 把录音转文字（Voice Memos 自带转写，或直接上传给 Claude）。**不要修改转写里的口误。**
3. 在 Claude Project 贴：

```
BASELINE speaking. Here is my unedited 2-minute transcript:
<粘贴>
Compute: total words, WPM (words / 2), filler count (um, uh, like, you know, so... at sentence start),
self-corrections / restarts, longest run-on, and the 3 biggest issues. Then give the SESSION CARD with type: baseline.
```

## 2. 听力：3 分钟理解率（10 分钟）

1. 选 **固定的一档 podcast**（建议 Hard Fork），播放最新一期里 **从未听过** 的 3 分钟片段。
2. 只听一遍，不看字幕。然后在 Claude Project 用英文写或说出你听到的要点。
3. 再贴上该片段的官方文稿或 YouTube 字幕：

```
BASELINE listening. My summary: <...>
Transcript: <...>
Estimate my comprehension % (main points + details + tone), list what I missed and why.
```

## 3. 主观自评（2 分钟）

每项 1–5 分：
- 开会时能主动插话
- 闲聊时能接住梗、玩笑
- 打电话办事不慌
- 听不懂时敢直接问

## 4. 记录

把数字填进 `progress/measurements.md` 的表格，卡片贴进 `progress/inbox.md`。
