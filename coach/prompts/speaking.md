# 口语日（周二 / 周四，20–30 分钟）

1. 打开 Claude Project → 点 **语音模式**。
2. 说 **"speaking"**。教练按本周计划选工作场景，直接开始。
3. 对练 10–12 分钟 → 教练给反馈，让你把更好的说法说一遍 → 可以再来一轮变化版。
4. 结束就关掉，不用复制任何东西。

想指定场景也可以直接说，比如："speaking, design review, you're a skeptical senior engineer"。

## 对练时提醒自己

- 每次回答 **至少 3 句**，别只说 "Yeah, sounds good."
- 卡住时用缓冲语继续说，别沉默："Let me think about that for a sec..." / "So what I'm getting at is..."
- 被插话时拿回话语权："Sorry, let me just finish this thought..."
