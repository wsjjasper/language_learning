# 生活场景日（周五，20–30 分钟）

1. 打开 Claude Project → 点 **语音模式**。
2. 说 **"life"**。教练按本周计划选场景（small talk / 打电话办事 / 社交轮换），直接开始。
3. 对练 → 反馈 → 同一场景换个变化再来一轮。
4. 结束就关掉。

## 小技巧

- small talk 的目标不是信息准确，而是 **接得住、能抛回去**：回答 + 一个细节 + 反问。
- 打电话时练这些救命句：
  - "Sorry, could you spell that for me?"
  - "Just to make sure I got that right, ..."
  - "Can you slow down a bit? The connection's not great."
- 听不懂梗时直接问："Wait, what's that from?"。美国人通常很乐意解释，这本身就是 small talk。
- 反馈时可以问一句：`What did a native speaker expect me to say that I didn't?`
